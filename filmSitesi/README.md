# 🎬 Movie Website

## 📖 Proje Hakkında

**Movie Website**, HTML, CSS ve JavaScript kullanılarak geliştirilmiş modern bir film platformu arayüzüdür. Projede kullanıcı deneyimini artırmak amacıyla kaydırılabilir film listeleri, hover animasyonları ve Dark Mode (Açık/Koyu Tema) desteği gibi etkileşimli özellikler yer almaktadır.

## ✨ Özellikler

- 🎥 Modern ve kullanıcı dostu arayüz
- 📂 Kategorilere ayrılmış film listeleri
- ⏩ Yatay kaydırılabilir içerikler
- 🌙 Dark Mode desteği
- 🎨 Hover animasyonları ve geçiş efektleri
- ⚡ JavaScript ile dinamik kullanıcı etkileşimleri

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome
- Google Fonts

## 🎯 Projenin Amacı

Bu proje, front-end geliştirme becerilerini geliştirmek amacıyla hazırlanmıştır. Çalışma kapsamında HTML, CSS ve JavaScript kullanılarak modern web tasarımı, DOM manipülasyonu, Flexbox yapısı, animasyonlar ve tema yönetimi gibi temel konular uygulamalı olarak geliştirilmiştir.
